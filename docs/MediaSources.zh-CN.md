# 媒体源：Navidrome / OpenSubsonic

第一版仅支持单服务器、单账号：连接、专辑分页（每页50项）、专辑歌曲、
服务器内歌曲搜索（每页50项）、封面、播放及加入现有队列。
不包含 Jellyfin、WebDAV、远程歌单编辑、收藏同步或多服务器同时浏览。

在 Media Sources 输入服务器根地址（可包含反向代理路径）、用户名、密码。
远程服务器建议 HTTPS；允许本地 HTTP，但没有传输加密。不跟随重定向，
请填写最终地址。认证使用 Subsonic 随机盐 token 协议。
勾选保存后使用 QtKeychain，禁用不安全回退；凭据库不可用时仅本次运行有效。
断开会禁止自动恢复并尝试删除已存凭据，删除失败会提示重试。

歌曲身份由服务器、账号、远端歌曲 ID 共同确定，不混入本地曲库。
数据库和队列不保存密码或带认证参数的播放地址。播放旧队列必须连接原服务器
和账号，不会回退到网易云或其他来源。

第一版先获取音频到本机缓存再交给现有 GStreamer 播放，因此首次播放需要等待
下载完成，单文件上限512MiB。之后支持暂停、继续和拖动进度。
已完成音频纳入现有音频缓存清理，保留正在使用的文件；封面单独保存，
音频清理不删除封面。暂不接服务器歌词或边下载边播。

自动化测试命令见 [英文说明](MediaSources.md)。测试使用临时数据目录、随机测试
账号、仅监听本机的服务，以及已有合法测试歌曲的副本，不改真实曲库或安装后台服务。
结果保存在 `.task/subsonic-test-*`。后端测试不代表视觉验收。
