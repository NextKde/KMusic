# 交付路线

[English](Roadmap.md)

1. 建立独立仓库、固定 Kos.Ui 依赖、Qt 应用入口及已有音乐后端的来源记录。
2. 完成方角窗体、侧栏、新发现、播放器、原创示例以及真实本地导入/播放，交出可供 VM 审查的首版。
3. 逐项比较实际 App 与 Forma，建立组件对应/差异清单，通用修复回归组件库并更新固定版本。
4. 补齐搜索、详情、队列、歌单、歌词、空态及错误处理。
5. 仅在 VM 迭代浅深色、尺寸和功能验收，回归组件库使用点，解决主要问题并记录边界。
6. 在 NextKde/nextkdeMusic 发布经审阅的源码与使用说明。建仓不代表正式版本发布或 UI 验收通过。

协调检查点保存在忽略的 `.task/state.md`，定时接续时不得重复启动开发者。
