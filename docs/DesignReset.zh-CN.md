# 整体设计校正（2026-10-21 用户最新明确要求）

本文件覆盖早期材质评审中允许使用 KWin/KF6 原生模糊的实现路线。
此前局部组件通过记录不代表整体界面通过；当前整体外观被用户否定，重新验收。

## 五条设计基准

1. **内容框架：Apple Music。** 侧栏、发现/精选、专辑架、歌曲列表、正在播放及常驻播放器采用其信息组织、比例和层级。页面首先是音乐产品，不是组件展示。
2. **应用外观：kos-settings。** 整体外壳及自绘窗口装饰器参考真实 kos-settings；方角外窗、右侧窗控、拖动/缩放/最大化等行为均落实。不得把此参考仅缩减成三个按钮。
3. **组件细节：Forma。** 阴影、交互反馈、圆角、字体、间距和动画对照本机 source-5bdb550；实际实现仍使用 Kos.Ui，共享修复回归 Gallery。
4. **液态效果是重点，必须保留。** 去掉的是生硬整圈描边和浮雕感，不能把控件改成普通扁平块。保留背景采样、折射、柔和方向性反光、按压展开和运动反馈，同时保证内容清晰。
5. **透明和模糊：纯 QML。** 不使用 KWin 液态玻璃、KF6WindowSystem 模糊请求或平台窗口效果适配；不改 KWin 配置。侧栏采样本应用真实页面/封面/背景 underlay，在 QML 场景内完成透明、模糊与液态材质。文字和图标保持清晰。不得把桌面墙纸复制进客户端伪装成跨窗口采样。

## 首个交付关口

先交一张实际运行的完整主界面（主尺寸 1280×800，再查 1024×640），同时覆盖外壳、侧栏、内容区、常驻播放器。协调者按整体观感验收后才继续铺其他页面。

- 不再用默认字体符号拼出导航和播放图标；采用一致的真实图标系统。
- 收敛标题、导航、行高、播放器和卡片的比例；不允许每个区域像不同产品。
- 移除用于填满首页的重复抽象占位封面；优先使用已接入音源的真实内容与封面；未接通的内容明确空态，不冒充可播放推荐。
- 使用现有实际音源与播放功能，不为视觉校正重做后端。
- 正常、悬停、按下和运动状态都应看见液态材质，而不是只在测试控件页面里出现。
- 每次仍截双库新图并按原频率发布，旧候选和问题图保留历史，不冒充当前进展。

## 退出旧路线

停止继续开发 NativeReview、CaptureArea、KWayland 窗口坐标及原生模糊验证工具；从应用生产构建和启动路径移除相关依赖/代码。已完成的真实音源、试听状态、歌词与重试功能保留并回归。纯 QML 液态渲染成本需针对实际窗口观察，不以“纯 QML”直接宣称零成本。
