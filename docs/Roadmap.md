# Delivery roadmap

[简体中文](Roadmap.zh-CN.md)

1. Establish independent repository, pinned Kos.Ui dependency, standalone Qt app
   and attributed reuse of the existing music backend. No runtime claim yet.
2. Implement square window chrome, discovery/sidebar/player, original fixtures
   and real local import/playback; submit the first VM-reviewable milestone.
3. Inspect the actual app and Forma references; maintain a component inventory,
   return portable fixes upstream and pin their reviewed component revision.
4. Complete search, details, queue, playlists, lyrics and empty/error handling.
5. Repeat VM visual and functional review in both appearances and supported sizes;
   regress upstream consumers. Resolve material issues and document remaining scope.
6. Publish the reviewed source and usage instructions in NextKde/nextkdeMusic.
   Initial repository publication is not a versioned release or UI sign-off.

The durable coordinator checkpoint is ignored .task/state.md. Do not restart
already-running work or spawn duplicate developers on scheduled follow-ups.
