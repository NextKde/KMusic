# Local Music

Local Music provides Songs, Albums, Artists, Playlists and Folders in one library page.

- Folder import recursively indexes audio using the existing TagLib scanner. Metadata and embedded artwork come from the files; missing covers use placeholders. Folder management displays scan status and warnings.
- The header search searches the local library and opens song results. Queries also filter album and artist groups and can be cleared.
- Selecting a song or Play builds a queue from the displayed collection and uses the existing local playback engine, playback modes, seeking and sidecar LRC support.
- Device playlists support creation, renaming, removal, adding tracks and removing playlist entries without deleting audio files.
- Device favorites and history are available from Playlists, may contain online tracks, and remain separate from platform account data.
- Folders can be rescanned or removed after confirmation. Removing a root removes its index and playlist references, never disk files; removal is disabled during scanning.

Build/start success is not functional or visual acceptance. No screenshots, automated interaction or tests were performed for this batch; the user reviews using their own music files.
